# Lumina - Academic AI Assistant

A modern, clean AI assistant for researchers.

## How to Run

1.  Open `c:\Lumina\index.html` in any modern web browser.
2.  Ensure you have an internet connection (for the Gemini API).

## Features

*   **Ask Anything Mode**: Chat with Lumina for general academic queries.
*   **Paper Assistance Mode**: Provide your paper's details (Title, Abstract, etc.) to get tailored assistance.
*   **Powered by Gemini**: Uses Google's Gemini 1.5 Flash model for fast, intelligent responses.

## Structure

*   `index.html`: The application structure.
*   `style.css`: Premium styling (Vanilla CSS).
*   `app.js`: Application logic and API integration.
